Welcome to Stackly API

The Stackly API is organized around REST. Our API has predictable resource-oriented URLs, accepts form-encoded request bodies, returns JSON-encoded responses, and uses standard HTTP response codes.

Base URL
https://api.stackly.com/v1

Authentication

The Stackly API uses API keys to authenticate requests. You can view and manage your API keys in the Dashboard once you log in.

Your API keys carry many privileges, so be sure to keep them secure! Do not share your secret API keys in publicly accessible areas such as GitHub, client-side code, etc.
Authentication Header Example
Authorization: Bearer YOUR_API_KEY
POST
/chat/completions

Creates a model response for the given chat conversation.

Request (cURL)
curl https://api.stackly.com/v1/chat/completions \ -H "Content-Type: application/json" \ -H "Authorization: Bearer YOUR_API_KEY" \ -d '{ "model": "stackly-llm-turbo", "messages": [ { "role": "user", "content": "Hello!" } ] }'
Response (JSON)
{ "id": "chatcmpl-123", "object": "chat.completion", "created": 1677652288, "choices": [{ "index": 0, "message": { "role": "assistant", "content": "Hello there, how may I assist you today?" }, "finish_reason": "stop" }], "usage": { "prompt_tokens": 9, "completion_tokens": 12, "total_tokens": 21 } }
